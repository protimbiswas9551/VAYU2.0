# 🌍 VAYU 2.0 — Weather Intelligence Dashboard

VAYU 2.0 is a modern, cinematic weather web application built with React, TypeScript, and Tailwind CSS. It delivers real-time weather insights, air quality data, and interactive visualizations in a sleek, professional UI.

---

## 🚀 Features

### 🌤️ Real-Time Weather Data

Get accurate, real-time weather conditions including temperature, wind speed, humidity, and precipitation probability using live APIs.

### 📍 Smart City Search

Search for any city worldwide with instant geolocation and dynamic weather updates.

### 🕒 Hourly Forecast

View a detailed 24-hour weather forecast with temperature trends and rain probability.

### 📅 7-Day Forecast

Plan ahead with a complete weekly weather overview including highs, lows, and conditions.

### 🌫️ Air Quality Index (AQI)

Monitor pollution levels including PM2.5, PM10, CO, and NO₂ with categorized AQI indicators.

### ☀️ UV Index Tracker

Stay protected with real-time UV index levels and safety insights.

### 💨 Wind Analyzer

Visualize wind speed trends using an interactive chart.

### ⚠️ Smart Weather Alerts

Receive automated alerts for extreme conditions like heatwaves, heavy rain, and strong winds.

### 🌐 Animated 3D Globe

Experience a visually stunning animated globe background powered by Three.js.

### 🎨 Modern UI/UX

* Glassmorphism design
* Smooth animations
* Responsive layout
* Dark themed interface

---

## 🛠️ Tech Stack

* **Frontend:** React + TypeScript
* **Styling:** Tailwind CSS
* **Routing:** React Router
* **Data Fetching:** React Query
* **3D Visualization:** Three.js + react-globe.gl
* **Icons:** Lucide React
* **APIs:** Open-Meteo (Weather & Air Quality)

## 📦 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/vayu2.git
cd vayu2
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

### 4. Open in Browser

```
http://localhost:5173
```
